# 🛒 Omni Retail POS & Inventory Management System

A high-performance, responsive Point of Sale (POS) and Inventory Management web application built for retail stores, supermarkets, and pharmacies.

## ✨ Key Features
- **Fast Checkout Interface:** Instant barcode scanning, keyboard hotkeys, and split payments.
- **Real-Time Inventory Control:** Automated low-stock badge alerts and expiry tracking.
- **WhatsApp Digital Billing:** Automated invoice delivery via WhatsApp API.
- **Udhaar / Credit Ledger:** Integrated customer CRM for debt management and credit tracking.
- **Business Intelligence:** Daily profit/loss analytics and CSV export capabilities.

## 🛠️ Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Zustand
- **Backend:** Node.js / Express API
- **Database:** SQLite / PostgreSQL
